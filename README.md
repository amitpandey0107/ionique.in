# Ionique Research static website

Single-page HTML, CSS, and JavaScript website with no build step or backend.

## Open the website

Open `index.html` in a modern browser. Media uses relative paths from the project root.

## Media assets

- `Ionique-Research.mp4` is the supplied presentation video. It loads only after the visitor presses Play.
- Product and deployment images are extracted to `assets/ionique/` from the 17-page source PDF. The filenames retain their source page and embedded-image order. They are used for the hero, configuration gallery, mode imagery, support-drone section, and packing sequence.
- `logo_2.jpeg`, `logo.jpeg`, and `energy_partner.jpeg` are also supplied in the project root; confirm their subjects and usage rights before using them on the published site.

## Update content

Edit the relevant section in `index.html`. Design tokens and responsive layouts are in `css/style.css`; navigation, scroll behavior, gallery selection, image dialog, and video playback are in `js/script.js`.

## Before publication

Confirm the four vehicle configuration names, support-drone terminology and claims, award attribution, technical specifications, commercial terms, contact details, and media permissions. Claims are reproduced from the supplied document and have not been independently verified.
